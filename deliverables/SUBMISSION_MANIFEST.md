## Suggested submission wording

This project improves the presentation and maintainability of the OsdagBridge
PyLaTeX design report. The work adds centralized report styling, repeated
longtable headers, clearer vehicle and footpath load tables, corrected display
units, utilization-ratio and material-quantity charts, and safer handling of
optional figures. The implementation reads existing design inputs and outputs;
it does not replace or alter the structural design calculations.

## Accuracy note

The documentation deliberately identifies remaining limitations, including
some unavailable engineering figures, incomplete End Diaphragm quantity data,
some blank backend load fields, Table 5.4 pagination refinement, and the footer
page-count discrepancy. These should not be described as fully fixed in the
submission.
